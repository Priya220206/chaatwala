# Chaatwala Streamlit Website

## Run locally
1. Install Python 3.9 or newer.
2. Open a terminal in this folder.
3. Run:
   ```bash
   pip install -r requirements.txt
   streamlit run app.py
   ```

## Deploy on Streamlit Community Cloud
1. Upload `app.py` and `requirements.txt` to a GitHub repository.
2. Visit https://share.streamlit.io/
3. Choose the repository, branch, and `app.py` as the main file.
4. Click Deploy.

The app uses internet-hosted dish photos, so photos require an internet connection. Image results come from a tag-based public image source and should be checked before publishing.
